## [0.1.0] - 2026-08-16

### Added

- Initial release with 20 promoted skills across 2 buckets (engineering, productivity)
- Engineering skills: ai-rebase, continue-debug, data-engineer, devops-engineer, drawio-diagram, frontend-qa, git-commit-message, git-group-commit-message, git-pr-message, implement-tdd-autonomously, ios-qa, pm, react-native-blueprint, reverse-wireframe-ui, vector-designer
- Productivity skills: decomposition-reconstruction, linear-worker, markdown-to-pdf, restore, save-and-exit
- Claude Code plugin packaging (plugin.json + marketplace.json)
- Codex/Cursor support via agents/openai.yaml per skill
- Developer tooling: Taskfile.yml with list, sync, link, validate tasks
- Skill template for contributors
- AGENTS.md with AAIF-compliant structure
