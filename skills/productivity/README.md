# Productivity

General workflow tools, not code-specific. Promoted: every skill here ships in the plugin and is listed in the top-level README.

**User-invoked**

<!-- skills:start -->
- **[decomposition-reconstruction](./decomposition-reconstruction/SKILL.md)** — Use when dealing with complex systems that need simplification, identifying bottlenecks or critical failure points, redesigning architecture or processes for better performance, breaking down problems that feel overwhelming, analyzing dependencies to understand ripple effects, user mentions "this is too complex", "where's the bottleneck", "how do we redesign this", "what are the key components", or when optimization requires understanding how parts interact.
- **[linear-worker](./linear-worker/SKILL.md)** — Use when the user wants to monitor Linear tickets assigned to a user and react to comments, status changes, or stale tickets. Use when setting up a recurring routine or loop that watches Linear for activity and takes action (responds, flags, nudges, summarizes).
- **[markdown-to-pdf](./markdown-to-pdf/SKILL.md)** — Convert markdown to PDF, create PDF from .md file, render markdown as print-ready document. Use when: "convert markdown to pdf", "create pdf out of this file", "render this as pdf", "make a pdf from markdown", or any request to turn a .md file into a styled PDF document.
- **[pickup](./pickup/SKILL.md)** — Load .scratch/CONTINUE.md, reconcile it with the workspace, and continue the saved work.
- **[wrapup](./wrapup/SKILL.md)** — Save current session state to .scratch/CONTINUE.md and prepare for a safe user-controlled exit.
